# Restaurante App

## Nombre

Efren Jaramillo

## Descripción

Una pequeña aplicación de restaurante desarrollada en Python, utilizando programación orientada a objetos y una interfaz gráfica con Tkinter. La aplicación permite iniciar sesión y administrar productos mediante operaciones como registrar, consultar, actualizar y eliminar.

## Funciones principales

- Inicio de sesión.
- Consulta de usuarios.
- Registro de productos.
- Consulta de productos.
- Actualización de productos.
- Eliminación de productos.
- Guardado de productos en un archivo JSON.

## Tecnologías

- Python
- Tkinter
- JSON

## Ejecución

Para ejecutar el programa, abre una terminal dentro de la carpeta del proyecto y ejecuta:

```bash
python main.py
```
